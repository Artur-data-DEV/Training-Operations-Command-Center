# SDK Gaps Runbook

Use this fallback whenever an artifact cannot be created reliably with `now-sdk` on the current release.

## Process

1. Mark code section with `requires verification`.
2. Create/update the artifact manually in instance UI.
3. Document exact steps and screenshots in this folder.
4. Export and reconcile changes back into source control.

## Typical Gaps

- Virtual Agent topic packaging
- Service Portal visual composition
- UI Builder workspace layout metadata
