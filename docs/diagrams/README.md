# TOCC Implementation Diagrams

This folder centralizes visual implementation artifacts to support incremental delivery.

## Files

- `system-context.md`: platform context, personas, and app layers.
- `domain-model.md`: table relationships focused on TOCC core entities.
- `reservation-lifecycle.md`: end-to-end reservation to attendance lifecycle.

All diagrams use Mermaid for direct rendering in Markdown-capable viewers.
